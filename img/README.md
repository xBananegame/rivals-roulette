# Charakterbilder / Character images

Lege hier PNG-Dateien mit exakt diesen Namen ab – sie werden automatisch geladen.
Fehlende Bilder sind kein Problem: Dann zeigt die Seite eine Initialen-Kachel.

Put PNG files with exactly these names in this folder – they are loaded automatically.
Missing images are fine: the site falls back to an initials tile.
